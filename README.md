# 💎 Carat の工作台

一个以 **SEVENTEEN 应援色**（玫瑰石英粉 + 宁静蓝）为主题的个人工作台网页应用，手机优先，同时适配电脑端。

## ✨ 功能模块

| 模块 | 说明 |
|------|------|
| 🏠 首页仪表盘 | 今日待办、关注股票、本月支出、热榜更新一览 |
| 📅 日历计划 | 仿苹果风格的月历，支持新增/删除/完成任务；每周固定健身课/钢琴课可一键生成 |
| 📈 股票盯盘 | 接入腾讯财经实时行情，支持 A股/港股/美股，手动刷新 |
| 💰 记账本 | 只记支出，快速记账，月度分类统计 |
| 🔥 热点聚合 | 微博/知乎/B站/抖音/小红书热榜，支持 App 唤起 |
| 💬 AI 复盘 | 记录每日复盘，一键生成 AI 建议，辅助自媒体规划 |

## 🚀 快速开始

### 方法一：本地直接打开
1. 下载本项目所有文件。
2. 用浏览器直接打开 `index.html` 即可使用（数据存浏览器本地）。

### 方法二：部署到 GitHub Pages
1. 把项目代码 push 到一个 GitHub 仓库。
2. 进入仓库 Settings → Pages → Source 选择 main 分支 / root。
3. 访问生成的 Pages 链接即可。

## 💾 数据同步（推荐）

工作台支持把数据存到 **GitHub Gist**，实现跨设备同步。

### 获取 GitHub Token
1. 登录 GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)。
2. 点击 Generate new token (classic)。
3. 勾选 `gist` 权限，生成后复制 Token。

### 在工作台中配置
1. 打开工作台，点击顶部的 **配置**。
2. 粘贴 GitHub Token，Gist ID 留空（首次会自动创建）。
3. 点击 **连接 Gist**。

> 连接成功后，Token 和 Gist ID 会安全地保存在当前浏览器中，所有数据修改会自动同步到 Gist。

## 📈 股票代码格式

支持 A股、港股、美股：

| 市场 | 代码示例 |
|------|---------|
| A股 | `sh000001`（上证）、`sz000001`（平安银行） |
| 港股 | `hk00700`（腾讯控股） |
| 美股 | `usAAPL`（苹果） |

## 🔥 热榜与 App 唤起

- 点击「刷新」可获取微博、知乎、B站、抖音、小红书等平台热榜。
- 点击各平台卡片上的「打开 App」按钮，会尝试唤起对应 App（需手机上安装）。

## 🤖 AI 复盘

在「AI 复盘」页面写下当天的想法、灵感或困惑，点击 **AI 给我建议**，会基于当前内容给出自媒体起步与优势挖掘建议。
